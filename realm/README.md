# Realm

The realm holds durable context around the summoner's intentions.

Projects, research, decisions, drafts, and other material that should outlive
an audience or executor belong here. Results meant for review or use belong in
`realm/artifacts/`; machine bookkeeping belongs in `runtime/`.

Small learned guides for recurring work belong in
`realm/practices/<spirit>/`. They are durable local context, not core law or
execution authority.

The realm is not a queue. A project can persist while no working is running and
no attention is required.
