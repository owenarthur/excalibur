# Practices

Practices are small markdown guides for work a spirit performs repeatedly.
They give the spirit a stable place to retain how the summoner likes that work
done and to incorporate later feedback.

Keep them under `realm/practices/<spirit>/`. Read a guide when its routine
matches the task; do not attach the whole directory to every prompt. Prefer a
few useful notes over a comprehensive manual.

A practice grants no authority. It does not open a spellbook, bind a cast,
widen a writable root, or replace identity, cornerstone, ritual, memory, or
project documentation.
