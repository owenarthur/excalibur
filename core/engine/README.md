# Runtime Code

In a full installation, the harness runtime code lives here.

This scaffold intentionally omits that code. The markdown hierarchy preserves
the content and constitutional layer from which an implementation is raised.

The runtime should:

- load spirit identities and spellbook manifests from markdown
- reread effective identity at every run boundary
- enforce exact roots independently of human-facing controls
- distinguish available manifests from casts with real bound handlers
- expose one real foreground transport
- preserve exact continuity across several audiences
- mirror turns into `runtime/<spirit>/conversations/`
- give workings durable identity, one claimant, leases, checkpoints,
  cancellation, and one terminal outcome
- treat generic provider agents as ephemeral executors beneath workings
- land validated results as artifacts or named deliverables
- create attention only for review, decision, failure, approval, or
  intervention
- write machine state atomically and recover honestly
- use the host's native supervisor
- bind locally unless authenticated outward exposure is deliberate
- preserve realm and runtime across source release and rollback
- enforce module locks, contribution classes, collision refusal, explicit
  authority acceptance, staged promotion, and receipts when modules are used

The template does not choose a web framework, supervisor, session manager, or
model provider. Those are means. The laws are explicit authority, durable
custody, truthful capability, legible recovery, and useful deliverables.
