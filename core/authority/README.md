# Authority

Owner-reviewed authority lives here. The engine rereads each spirit identity at
every run boundary; a spirit cannot alter this tree through its ordinary realm
authority.

- `chargebook.md` is the shared charge policy.
- `spirits/<name>/identity.md` is the enforceable identity and authority
  manifest for one durable office.
- `spirits/<name>/cornerstone.md` is that office's behavioral law.
- `spirits/<name>/rituals/` contains read-only rites.

Module requests are accepted or refused by a separate explicit owner decision.
A module manifest never rewrites this tree and never grants itself authority.
