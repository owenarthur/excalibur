# Core

Core is reviewed source and owner-controlled authority.

- `engine/` is where a raised implementation's runtime code belongs.
- `authority/` holds charge law and durable spirit identities.
- `spellbooks/` holds capability and cast manifests.
- `portals/` holds always-on surface law.
- `services/` holds portable native-supervisor material.
- `extensions/` defines the external module composition seam.

A spirit's ordinary realm authority must not include this tree. Releases may
replace reviewed core material through explicit promotion while preserving
realm and runtime.
